1. PCR001–PCR006 Static Prefix CI Linter (pcr_lint.py) ​

Zero-dependency Python 3 AST + regex scanner checking Python, TypeScript, JavaScript, and C# codebases for missing/high-cardinality prompt_cache_key (PCR001), Pos-1 timestamps (PCR002), unsorted json.dumps schemas (PCR003), early RAG chunks (PCR004), unsupported GPT-5.6 PTU-M breakpoints (PCR005), and missing cached_tokens telemetry (PCR006).

Scan-integrity failures (PCR000) return exit code 1 rather than a false-green result: missing/inaccessible targets, unsupported explicit file types, empty/excluded-only directories, unreadable/non-UTF-8 sources, and Python parse errors. Run python pcr_lint.py --self-test to exercise these failure paths and the six readiness rules; --json preserves structured findings for CI [Arch].

Deeply nested Python source that exceeds the recursion limit during AST parsing or expression rendering also produces PCR000 (file-level line 1) instead of a traceback. The CLI continues scanning other files/targets, preserves their findings in text and --json output, and exits 1; incomplete AST results are never certified. The self-test covers both processing phases plus real deep-source CLI fixtures. This is a local scanner integrity rule, not an Azure service limit; it does not raise Python's recursion limit or evaluate source expressions [Arch].

PCR001 also rejects blank (empty or whitespace-only) and non-string Python AST constants, such as None, booleans, numbers, and bytes, on both responses.create and chat.completions.create. This is a local deterministic-routing readiness policy applied to matching calls regardless of model, not an Azure API requirement. The scanner inspects constant nodes without evaluating source expressions: names, calls, containers, arithmetic, concatenation, and f-strings are not resolved or certified by this check; the existing high-cardinality name heuristic still applies. Retain runtime assertions for computed keys. The self-test covers accepted strings, rejected constants, unevaluated expressions, and text/JSON CLI failures [Arch].

#!/usr/bin/env python3
"""PCR001-PCR006 Static Prompt-Caching Readiness Linter (Python AST + Regex).

Zero-dependency CLI scanner for GPT-5.6, GPT-6, and GPT-6.1 migrations.
PCR000 reports incomplete or invalid scans; all findings exit nonzero.
Last verified: 2026-11-18 21:21 PST
Usage:
    python pcr_lint.py ./src
    python pcr_lint.py ./src --json

License: MIT
"""

from __future__ import annotations

import argparse
import ast
import json
import os
import re
import subprocess
import sys
from dataclasses import asdict, dataclass
from pathlib import Path
from tempfile import TemporaryDirectory
from unittest.mock import patch

SKIP_DIRS = {".git", ".venv", "venv", "node_modules", "__pycache__", "dist", "build"}
TARGET_EXTS = {".py", ".ts", ".js", ".cs"}
SELF_PATH = Path(__file__).resolve()

VOLATILE_TOKENS_RE = re.compile(
    r"\b(datetime\.now|datetime\.utcnow|DateTime\.UtcNow|Date\.now|time\.time|uuid4|request_timestamp|req_ctx|request_ctx)\b"
)
DYNAMIC_KEY_RE = re.compile(
    r"(user_id|request_id|uuid4|trace_id|engagement_id|engagement_code|matter_id|client_id|cost_center)",
    re.IGNORECASE,
)
GPT56_OR_6_RE = re.compile(r"gpt-(5\.6|6(\.1)?)", re.IGNORECASE)
PTU_56_RE = re.compile(r"gpt-5[.-]6.*ptu|ptu.*gpt-5[.-]6", re.IGNORECASE)


@dataclass
class Finding:
    rule: str
    file: str
    line: int
    message: str


def scan_python_ast(path: Path, source: str) -> list[Finding]:
    findings: list[Finding] = []
    try:
        tree = ast.parse(source, filename=str(path))
    except SyntaxError as exc:
        return [Finding("PCR000", path.as_posix(), exc.lineno or 1, f"Python syntax could not be parsed: {exc.msg}")]

    rel = path.as_posix()
    for node in ast.walk(tree):
        if not isinstance(node, ast.Call):
            continue

        func_src = ast.unparse(node.func) if hasattr(ast, "unparse") else ""
        call_src = ast.unparse(node) if hasattr(ast, "unparse") else ""
        kw_names = {kw.arg: kw.value for kw in node.keywords if kw.arg}

        # PCR001: Missing, invalid constant, or per-user/request prompt_cache_key
        if func_src.endswith(("responses.create", "completions.create")):
            if "prompt_cache_key" not in kw_names:
                findings.append(
                    Finding(
                        "PCR001",
                        rel,
                        node.lineno,
                        "LLM create() call omits prompt_cache_key (required for deterministic GPT-5.6+ routing).",
                    )
                )
            else:
                key_node = kw_names["prompt_cache_key"]
                key_expr = ast.unparse(key_node) if hasattr(ast, "unparse") else ""
                if isinstance(key_node, ast.Constant) and (
                    not isinstance(key_node.value, str) or not key_node.value.strip()
                ):
                    findings.append(
                        Finding(
                            "PCR001",
                            rel,
                            node.lineno,
                            "prompt_cache_key is a blank/non-string constant; local routing readiness policy requires a non-empty string constant.",
                        )
                    )
                elif DYNAMIC_KEY_RE.search(key_expr):
                    findings.append(
                        Finding(
                            "PCR001",
                            rel,
                            node.lineno,
                            f"prompt_cache_key interpolates high-cardinality identifier ({key_expr}); shard by hash(thread_id) % N instead.",
                        )
                    )

            # PCR005: Deprecated prompt_cache_retention on GPT-5.6+
            if "prompt_cache_retention" in kw_names and GPT56_OR_6_RE.search(call_src):
                findings.append(
                    Finding(
                        "PCR005",
                        rel,
                        node.lineno,
                        "prompt_cache_retention is deprecated on GPT-5.6+; use prompt_cache_options={'ttl': '30m'|'12h'}.",
                    )
                )

        # PCR003: json.dumps on schema / card / tool / context objects without sort_keys=True
        if func_src == "json.dumps" and node.args:
            arg0 = ast.unparse(node.args[0]) if hasattr(ast, "unparse") else ""
            if re.search(r"(tool|schema|card|context|ctx|rubric|taxonomy)", arg0, re.IGNORECASE):
                sort_kw = kw_names.get("sort_keys")
                is_sorted = isinstance(sort_kw, ast.Constant) and sort_kw.value is True
                if not is_sorted:
                    findings.append(
                        Finding(
                            "PCR003",
                            rel,
                            node.lineno,
                            f"json.dumps({arg0}) lacks sort_keys=True; key-order drift breaks Pos 1-4 prefix caching.",
                        )
                    )

    return findings


def scan_text_patterns(path: Path, source: str) -> list[Finding]:
    findings: list[Finding] = []
    rel = path.as_posix()
    lines = source.splitlines()

    for idx, line in enumerate(lines, start=1):
        # PCR002: Volatile timestamp/UUID injected inside system/developer message definition
        if re.search(r'role["\']?\s*[:=]\s*["\'](system|developer)["\']', line) or "sys_prompt" in line or "sys_text" in line:
            window = "\n".join(lines[max(0, idx - 3) : min(len(lines), idx + 4)])
            if VOLATILE_TOKENS_RE.search(window):
                findings.append(
                    Finding(
                        "PCR002",
                        rel,
                        idx,
                        "Live timestamp/UUID detected near system/developer prompt; keep Pos 1-3 100% static.",
                    )
                )

        # PCR004: RAG chunks placed ahead of static instructions in same template
        if re.search(r"(rag_chunks|search_results).*?(static_policy|system_prompt|domain_methodology)", line):
            findings.append(
                Finding(
                    "PCR004",
                    rel,
                    idx,
                    "Dynamic RAG/search content appears ahead of static instructions; move volatile grounding to Pos 6.",
                )
            )

        # PCR005: Explicit breakpoints sent to GPT-5.6 PTU-M deployment
        if "prompt_cache_breakpoint" in line and PTU_56_RE.search(source):
            findings.append(
                Finding(
                    "PCR005",
                    rel,
                    idx,
                    "prompt_cache_breakpoint detected alongside GPT-5.6 PTU identifier (breakpoints unsupported on 5.6 PTU-M).",
                )
            )

    # PCR006: Logs prompt_tokens or usage.input_tokens without reading cached_tokens anywhere in the wrapper module
    has_usage_tokens = "prompt_tokens" in source or bool(re.search(r"\busage\.input_tokens\b", source))
    if has_usage_tokens and "cached_tokens" not in source:
        line_no = next(
            (i for i, l in enumerate(lines, 1) if "prompt_tokens" in l or "input_tokens" in l),
            1,
        )
        findings.append(
            Finding(
                "PCR006",
                rel,
                line_no,
                "Module reads usage token counts without extracting input_tokens_details/prompt_tokens_details.cached_tokens.",
            )
        )

    return findings


def scan_path(target: Path) -> list[Finding]:
    all_findings: list[Finding] = []
    files: list[Path] = []

    def traversal_error(exc: OSError) -> None:
        all_findings.append(
            Finding("PCR000", Path(exc.filename or target).as_posix(), 1, f"Cannot enumerate scan directory: {exc}")
        )

    if target.is_file():
        if target.suffix.lower() not in TARGET_EXTS:
            return [Finding("PCR000", target.as_posix(), 1, "Unsupported scan file; expected .py, .ts, .js, or .cs.")]
        files = [target]
    elif target.is_dir():
        if target.name in SKIP_DIRS:
            return [Finding("PCR000", target.as_posix(), 1, "Scan target is an excluded directory.")]
        for root, dirs, names in os.walk(target, onerror=traversal_error):
            dirs[:] = sorted(d for d in dirs if d not in SKIP_DIRS)
            files.extend(
                p for name in names
                if (p := Path(root) / name).suffix.lower() in TARGET_EXTS
                and p.resolve() != SELF_PATH
            )
    else:
        return [Finding("PCR000", target.as_posix(), 1, "Scan target does not exist or is not an accessible file/directory.")]

    if not files and not all_findings:
        return [Finding("PCR000", target.as_posix(), 1, "No supported source files found after scan exclusions.")]

    for f in sorted(files):
        try:
            text = f.read_text(encoding="utf-8")
        except (OSError, UnicodeError) as exc:
            all_findings.append(Finding("PCR000", f.as_posix(), 1, f"Cannot read source as UTF-8: {exc}"))
            continue
        if f.suffix.lower() == ".py":
            try:
                all_findings.extend(scan_python_ast(f, text))
            except RecursionError:
                all_findings.append(
                    Finding("PCR000", f.as_posix(), 1, "Python AST processing exceeded the recursion limit; scan is incomplete.")
                )
        all_findings.extend(scan_text_patterns(f, text))
    # Deduplicate by (rule, file, line)
    seen: set[tuple[str, str, int]] = set()
    unique: list[Finding] = []
    for item in all_findings:
        key = (item.rule, item.file, item.line)
        if key not in seen:
            seen.add(key)
            unique.append(item)
    return unique


def run_self_test() -> int:
    clean_sample = (
        'import json\n'
        'def call_agent(client, tool_schemas):\n'
        '    ordered = json.dumps(tool_schemas, sort_keys=True)\n'
        '    res = client.responses.create(model="gpt-6-sol", prompt_cache_key="tax:scorer:v4:s0", input=ordered)\n'
        '    return res.usage.input_tokens, res.usage.input_tokens_details.cached_tokens\n'
    )
    assert scan_python_ast(Path("clean.py"), clean_sample) == [], "Expected 0 AST findings on clean sample"
    assert scan_text_patterns(Path("clean.py"), clean_sample) == [], "Expected 0 text findings on clean sample"

    bad_sample = (
        'import datetime, json\n'
        'MODEL = "gpt-5.6-ptu"\n'
        'sys_prompt = f"Now: {datetime.datetime.now()}"\n'
        'frag = f"{rag_chunks} then {system_prompt}"\n'
        'bp = {"prompt_cache_breakpoint": {"mode": "explicit"}}\n'
        'raw_tools = json.dumps(tool_schema)\n'
        'res = client.responses.create(model="gpt-5.6", input=raw_tools)\n'
        'tok = res.usage.input_tokens\n'
    )
    rules = {
        f.rule
        for f in (scan_python_ast(Path("bad.py"), bad_sample) + scan_text_patterns(Path("bad.py"), bad_sample))
    }
    expected = {"PCR001", "PCR002", "PCR003", "PCR004", "PCR005", "PCR006"}
    assert expected.issubset(rules), f"Expected all {expected}, got {rules}"

    invalid_keys = (
        '""', '" \\t\\r\\n"', '"\\u2003"', "None", "True", "False",
        "0", "42", "1.5", "1e309", "2j", 'b"shared:v1:s0"', "...",
    )
    # Compound expressions remain unresolved; scanning must never evaluate them.
    unresolved_keys = (
        "shared_key", "build_key()", 'f"shared:{shard}"',
        '"shared:" + str(shard)', "-1", "1+2j", "-1+2j",
        "1 / 0", '"x" * 1000000000', '{"scope": shared_key}', "set()",
    )
    valid_keys = ('"shared:v1:s0"', '"0"', '"shared:" "v1:s0"')
    key_samples: list[str] = []
    invalid_lines: list[int] = []
    for api in ("responses.create", "chat.completions.create"):
        for expression in invalid_keys + valid_keys + unresolved_keys:
            sample = f"client.{api}(prompt_cache_key={expression})\n"
            findings = scan_python_ast(Path("keys.py"), sample)
            if expression in invalid_keys:
                assert len(findings) == 1 and findings[0].rule == "PCR001", (expression, findings)
                assert findings[0].file == "keys.py" and findings[0].line == 1, findings
                assert "non-empty string constant" in findings[0].message, findings
                invalid_lines.append(len(key_samples) + 1)
            else:
                assert findings == [], (expression, findings)
            key_samples.append(sample)

    with TemporaryDirectory() as tmp:
        root = Path(tmp)
        clean = root / "clean.py"
        clean.write_text(clean_sample, encoding="utf-8")
        keys = root / "keys.py"
        keys.write_text("".join(key_samples), encoding="utf-8")
        for output_flags in ([], ["--json"]):
            result = subprocess.run(
                [sys.executable, str(SELF_PATH), str(clean), str(keys), *output_flags],
                capture_output=True, text=True, encoding="utf-8", check=False,
            )
            assert result.returncode == 1 and not result.stderr, result
            assert "PASSED" not in result.stdout, result.stdout
            if output_flags:
                findings = json.loads(result.stdout)
                assert [f["line"] for f in findings] == invalid_lines, findings
                assert all(f["rule"] == "PCR001" and f["file"] == keys.as_posix()
                           for f in findings), findings
            else:
                assert result.stdout.count("[PCR001]") == len(invalid_lines), result.stdout
        broken = root / "broken.py"
        broken.write_text("def broken(:\n", encoding="utf-8")
        invalid_utf8 = root / "invalid.py"
        invalid_utf8.write_bytes(b"\xff")
        unsupported = root / "notes.txt"
        unsupported.write_text("Not source code.", encoding="utf-8")
        empty = root / "empty"
        empty.mkdir()
        excluded = root / "excluded"
        (excluded / "node_modules").mkdir(parents=True)
        (excluded / "node_modules" / "broken.py").write_text("def broken(:\n", encoding="utf-8")
        mixed = root / "mixed"
        mixed.mkdir()
        (mixed / "clean.py").write_text(clean_sample, encoding="utf-8")
        (mixed / "broken.py").write_text("def broken(:\n", encoding="utf-8")
        multi = root / "multi"
        multi.mkdir()
        for suffix in (".py", ".ts", ".js", ".cs"):
            (multi / f"clean{suffix}").write_text("", encoding="utf-8")
        (multi / "node_modules").mkdir()
        (multi / "node_modules" / "broken.py").write_text("def broken(:\n", encoding="utf-8")

        for target in (
            root / "missing", empty, excluded, excluded / "node_modules",
            unsupported, broken, invalid_utf8, mixed, clean, multi,
        ):
            should_pass = target in (clean, multi)
            result = subprocess.run(
                [sys.executable, str(SELF_PATH), str(target), "--json"],
                capture_output=True, text=True, encoding="utf-8", check=False,
            )
            assert result.returncode == (0 if should_pass else 1), (target.name, result.stderr)
            findings = json.loads(result.stdout)
            if should_pass:
                assert findings == [], findings
            else:
                assert any(f["rule"] == "PCR000" for f in findings), findings

        result = subprocess.run(
            [sys.executable, str(SELF_PATH), str(clean), str(root / "missing")],
            capture_output=True, text=True, encoding="utf-8", check=False,
        )
        assert result.returncode == 1 and "[PCR000]" in result.stdout, result
        assert "PASSED" not in result.stdout, result.stdout
        with patch.object(Path, "read_text", side_effect=PermissionError("read denied")):
            assert scan_path(clean)[0].rule == "PCR000"
        for phase in ("parse", "unparse"):
            with patch.object(ast, phase, side_effect=RecursionError("source details must not be echoed")):

                assert len(findings) == 1 and findings[0].rule == "PCR000", findings

        deep_sources = root / "deep_sources"

        deep_call = deep_sources / "deep_call.py"

            'client' + '.nested' * 1500 + '.responses.create(prompt_cache_key="shared:v1:s0")\n',
            encoding="utf-8",
        )

        bad_key.write_text('client.responses.create(prompt_cache_key="")\n', encoding="utf-8")
        findings = scan_path(deep_sources)
        assert [(f.rule, f.file, f.line) for f in findings] == [
            ("PCR001", bad_key.as_posix(), 1),
            ("PCR000", deep_call.as_posix(), 1),
            ("PCR000", deep_parse.as_posix(), 1),
        ], findings
        for output_flags in ([], ["--json"]):
            result = subprocess.run(
                [sys.executable, str(SELF_PATH), str(clean), str(deep_call),
                 str(deep_parse), str(bad_key), *output_flags],
                capture_output=True, text=True, encoding="utf-8", check=False,
            )
            assert result.returncode == 1 and not result.stderr, result
            assert "PASSED" not in result.stdout and "Traceback" not in result.stdout, result.stdout
            if output_flags:
                findings = json.loads(result.stdout)
                assert [(f["rule"], f["file"], f["line"]) for f in findings] == [
                    ("PCR000", deep_call.as_posix(), 1),
                    ("PCR000", deep_parse.as_posix(), 1),
                    ("PCR001", bad_key.as_posix(), 1),
                ], findings
            else:
                assert result.stdout.count("[PCR000]") == 2, result.stdout
                assert result.stdout.count("[PCR001]") == 1, result.stdout
        with patch.object(os, "walk") as walk:
            def denied_walk(target, onerror):
                onerror(PermissionError(13, "enumeration denied", str(target)))
                return iter(())
            walk.side_effect = denied_walk
            assert scan_path(empty)[0].rule == "PCR000"

    print("✅ pcr_lint.py self-test PASSED (PCR000 scan integrity/AST recursion + PCR001 constant keys/CLI + PCR001–PCR006 verified).")
    return 0


def main() -> int:
    parser = argparse.ArgumentParser(description="PCR001-PCR006 static prompt-caching readiness linter; PCR000 scan failures.")
    parser.add_argument("paths", nargs="*", help="Files or directories to scan")
    parser.add_argument("--json", action="store_true", help="Emit findings as JSON")
    parser.add_argument("--self-test", action="store_true", help="Run built-in scan integrity and PCR001-PCR006 self-tests")
    args = parser.parse_args()

    if args.self_test:
        return run_self_test()

    if not args.paths:
        parser.error("Provide one or more paths to scan, or pass --self-test.")

    findings: list[Finding] = []
    for raw in args.paths:
        findings.extend(scan_path(Path(raw)))

    if args.json:
        print(json.dumps([asdict(f) for f in findings], indent=2))
    elif findings:
        for f in findings:
            print(f"{f.file}:{f.line}: [{f.rule}] {f.message}")
        print(f"\nFAILED: {len(findings)} scan integrity or prompt-caching readiness issue(s) detected.")
    else:
        print("PASSED: 0 PCR001-PCR006 violations detected.")

    return 1 if findings else 0


if __name__ == "__main__":
    sys.exit(main())

| extend cd = parse_json(Properties)

         input_tok = tolong(cd["gen_ai.usage.input_tokens"]), output_tok = tolong(cd["gen_ai.usage.output_tokens"]),
         cached_tok = tolong(coalesce(cd["gen_ai.usage.cached_tokens"], 0)),
         write_tok = tolong(coalesce(cd["gen_ai.usage.cache_write_tokens"], 0)),
         ttft_ms = todouble(cd["gen_ai.latency.ttft_ms"])
| extend uncached_tok = max_of(input_tok - cached_tok - write_tok, 0)
| extend norm_tok = case(  // Short-context (<=272K) weights; use 2x input/cache & 7.5x output if input_tok > 272000

def unique_json_object(pairs: list[tuple[str, Any]]) -> dict[str, Any]:

def percentile(values: list[float], pct: float) -> float:
    if not values:
        return 0.0
    ordered = sorted(values)
    idx = min(len(ordered) - 1, max(0, math.ceil((pct / 100.0) * len(ordered)) - 1))
    return ordered[idx]


def validate_record(
    rec: Any, row: int, *, require_acl_trimming: bool, forbid_raw_prompt_logging: bool
) -> list[str]:
    prefix = f"[ARG001] row-{row}:"
    if not isinstance(rec, dict):
        return [f"{prefix} execution record must be a JSON object."]

    failures: list[str] = []
    for field in ("case_id", "status", "assistant_response"):
        value = rec.get(field)
        if not isinstance(value, str) or (field != "assistant_response" and not value.strip()):
            failures.append(f"{prefix} {field} must be a string (non-empty for identifiers/status).")

    for field in ("tools_called", "retrieved_doc_ids"):
        value = rec.get(field)
        if not isinstance(value, list) or any(not isinstance(x, str) or not x.strip() for x in value):
            failures.append(f"{prefix} {field} must be an array of non-empty strings.")

    for field in ("pass_number", "input_tokens", "cached_tokens"):
        value = rec.get(field)
        minimum = 1 if field == "pass_number" else 0
        if type(value) is not int or value < minimum:
            failures.append(f"{prefix} {field} must be an integer >= {minimum}.")
    if (
        type(rec.get("input_tokens")) is int
        and type(rec.get("cached_tokens")) is int
        and rec["cached_tokens"] > rec["input_tokens"]
    ):
        failures.append(f"{prefix} cached_tokens must not exceed input_tokens.")

    duration = rec.get("duration_ms")
    if (
        type(duration) not in (int, float)
        or duration < 0
        or (isinstance(duration, float) and not math.isfinite(duration))
    ):
        failures.append(f"{prefix} duration_ms must be a finite number >= 0.")

    for field, required in (
        ("acl_trimmed", require_acl_trimming and bool(rec.get("retrieved_doc_ids"))),
        ("raw_prompt_logged", forbid_raw_prompt_logging),
        ("otel_capture_message_content", False),
    ):
        if (required or field in rec) and type(rec.get(field)) is not bool:
            failures.append(f"{prefix} {field} must be an explicit boolean.")

    return failures


def evaluate_trace(
    records: list[Any],
    *,
    max_p95_ms: float = 15000.0,
    min_pass2_cached_tokens: int = 1024,
    forbidden_tools: set[str] | None = None,
    required_tools: set[str] | None = None,
    require_acl_trimming: bool = True,
    forbid_raw_prompt_logging: bool = True,
) -> list[str]:
    deny = forbidden_tools if forbidden_tools is not None else DEFAULT_FORBIDDEN_TOOLS
    req = required_tools or set()
    failures: list[str] = []
    latencies: list[float] = []

    if not records:
        return ["[ARG001] Trace file contains zero execution records."]

    for i, rec in enumerate(records, start=1):
        schema_failures = validate_record(
            rec, i, require_acl_trimming=require_acl_trimming,
            forbid_raw_prompt_logging=forbid_raw_prompt_logging,
        )
        if schema_failures:
            failures.extend(schema_failures)
            continue

        case_id = rec["case_id"]
        status = rec["status"]
        if status != "ok":
            failures.append(f"[ARG001] {case_id}: terminal status is '{status}' (expected 'ok').")

        tools_used = rec["tools_called"]
        for tool in tools_used:
            if tool in deny:
                failures.append(f"[ARG002] {case_id}: invoked forbidden tool '{tool}'.")
        for req_tool in sorted(req):
            if req_tool not in tools_used:
                failures.append(f"[ARG002] {case_id}: missing required tool invocation '{req_tool}'.")

        answer = rec["assistant_response"]
        retrieved = set(rec["retrieved_doc_ids"])
        cited = CITATION_RE.findall(answer)
        if answer.count("[cite:") != len(cited):
            failures.append(
                f"[ARG003] {case_id}: malformed inline citation marker; expected [cite:ID] with a non-empty ID using only A-Z, a-z, 0-9, _, ., :, #, or -."
            )
        for cid in cited:
            if cid not in retrieved:
                failures.append(
                    f"[ARG003] {case_id}: unresolved inline citation '[cite:{cid}]' not in retrieved_doc_ids."
                )

        pass_num = rec["pass_number"]
        input_tok = rec["input_tokens"]
        cached_tok = rec["cached_tokens"]
        if pass_num >= 2 and input_tok >= min_pass2_cached_tokens and cached_tok < min_pass2_cached_tokens:
            failures.append(
                f"[ARG004] {case_id}: pass {pass_num} had {input_tok} input tokens but only {cached_tok} cached_tokens (<{min_pass2_cached_tokens})."
            )

        if require_acl_trimming and retrieved and rec.get("acl_trimmed") is False:
            failures.append(
                f"[ARG006] {case_id}: retrieved {len(retrieved)} document(s) with acl_trimmed=False (violates Gate A5 security trimming)."
            )

        if forbid_raw_prompt_logging and (
            rec.get("raw_prompt_logged") is True or rec.get("otel_capture_message_content") is True
        ):
            failures.append(
                f"[ARG007] {case_id}: telemetry logged raw prompt/message content (violates Gate A12 metadata-only OTel)."
            )

        latencies.append(rec["duration_ms"])

    p95 = percentile(latencies, 95.0)
    if latencies and p95 > max_p95_ms:
        failures.append(f"[ARG005] Latency p95 {p95:.0f}ms exceeds budget {max_p95_ms:.0f}ms.")

    return failures


def validate_contract(raw: Any) -> dict[str, Any]:
    if not isinstance(raw, dict):
        raise ValueError("contract must be a JSON object.")

    allowed_fields = {
        "max_p95_ms", "min_pass2_cached_tokens", "required_tools", "forbidden_tools",
        "require_acl_trimming", "forbid_raw_prompt_logging",
        "contract_version", "track", "metadata",
    }
    if any(field not in allowed_fields for field in raw):
        raise ValueError(
            "contract contains unsupported top-level fields; allowed fields: "
            + ", ".join(sorted(allowed_fields)) + "."
        )

    max_p95_ms = raw.get("max_p95_ms", 15000.0)
    if (
        type(max_p95_ms) not in (int, float)
        or max_p95_ms <= 0
        or (isinstance(max_p95_ms, float) and not math.isfinite(max_p95_ms))
    ):
        raise ValueError("max_p95_ms must be a finite number > 0.")

    min_cached = raw.get("min_pass2_cached_tokens", 1024)
    if type(min_cached) is not int or min_cached <= 0:
        raise ValueError("min_pass2_cached_tokens must be an integer > 0.")

    for field in ("required_tools", "forbidden_tools"):
        if field in raw:
            tools = raw[field]
            if not isinstance(tools, list) or any(
                not isinstance(tool, str) or not tool.strip() for tool in tools
            ):
                raise ValueError(f"{field} must be an array of non-empty strings.")

    for field in ("require_acl_trimming", "forbid_raw_prompt_logging"):
        if field in raw and type(raw[field]) is not bool:
            raise ValueError(f"{field} must be an explicit boolean.")

    return {
        "max_p95_ms": max_p95_ms,
        "min_pass2_cached_tokens": min_cached,
        "forbidden_tools": set(raw.get("forbidden_tools", list(DEFAULT_FORBIDDEN_TOOLS))),
        "required_tools": set(raw.get("required_tools", [])),

def main() -> int:
    parser = argparse.ArgumentParser(description="Deterministic CI release gate for enterprise AI agents.")
    parser.add_argument("trace_path", nargs="?", help="Path to JSONL trace evidence file.")
    parser.add_argument("--contract", help="Optional path to JSON acceptance contract file.")
    parser.add_argument("--max-p95-ms", type=float, default=15000.0, help="Maximum allowed p95 duration in ms.")
    parser.add_argument("--min-cached-tokens", type=int, default=1024, help="Minimum cached tokens on pass>=2.")
    parser.add_argument("--json", action="store_true", help="Emit machine-readable JSON output.")
    parser.add_argument("--self-test", action="store_true", help="Run built-in deterministic contract self-tests.")
    args = parser.parse_args()

    if args.self_test:
        return run_self_test()

    if not args.trace_path:
        parser.error("Provide a trace_path JSONL file or pass --self-test.")

    try:
        if args.contract:
            kwargs = load_contract(Path(args.contract))
        else:
            kwargs = validate_contract({
                "max_p95_ms": args.max_p95_ms,
                "min_pass2_cached_tokens": args.min_cached_tokens,
            })
    except (OSError, UnicodeError):
        print("Error: could not read UTF-8 acceptance contract.", file=sys.stderr)
        return 2
    except ValueError as exc:
        print(f"Error: invalid acceptance contract: {exc}", file=sys.stderr)
        return 2

    path = Path(args.trace_path)
    try:
        trace_text = path.read_text(encoding="utf-8")
    except (OSError, UnicodeError):
        print("Error: [ARG001] could not read UTF-8 trace evidence.", file=sys.stderr)
        return 2

    records: list[Any] = []
    for line_number, line in enumerate(trace_text.splitlines(), start=1):
        if not line.strip():
            continue
        try:
            records.append(json.loads(line, object_pairs_hook=unique_json_object))
        except RecursionError:
            print(
                f"Error: [ARG001] line-{line_number}: execution record JSON exceeds the parser nesting limit.",
                file=sys.stderr,
            )
            return 2
        except ValueError:
            print(
                f"Error: [ARG001] line-{line_number}: invalid JSON execution record (malformed JSON or duplicate object members).",
                file=sys.stderr,
            )
            return 2
    failures = evaluate_trace(records, **kwargs)

    if args.json:
        print(json.dumps({"passed": len(failures) == 0, "record_count": len(records), "failures": failures}, indent=2))
    elif failures:
        print(f"❌ Agent Release Gate FAILED ({len(failures)} violation(s)):")
        for f in failures:
            print(f"  - {f}")
    else:
        print(f"✅ Agent Release Gate PASSED ({len(records)} turn(s) verified clean).")

    return 1 if failures else 0


if __name__ == "__main__":
    raise SystemExit(main())
