Why It Matters

Failing over an LLM endpoint alone leaves enterprise agents broken if regional data-processing boundaries are violated, secondary KV caches choke on cold-start surges, or Cosmos/AI Search state lags behind.

Key Takeaway

Design Business Continuity at the AI Stamp level: pair Data-Zone/Regional PTU-M with secondary PAYG surge capacity, synchronize Cosmos DB + AI Search stamps, and verify <15s cutover via quarterly game-day drills.

Practical Application

Use the 4-failure-mode diagram and decision table below to align Risk/Compliance, Cloud Infrastructure, and AI Platform teams.

Why Traditional Stateless Web DR Fails for Enterprise AI ​

Most cloud disaster-recovery runbooks assume stateless compute tiers where Region B can immediately serve 100% of Region A's traffic at identical unit capacity. Production Microsoft Foundry platforms introduce four AI-specific continuity constraints [M] [Arch]:

  1. Data-Processing vs. Data-at-Rest Residency: A Global deployment stores configuration metadata in the resource region, whereas inference compute may execute globally [M]. Regulated workloads bound by geographic sovereignty must select Data Zone (US / EU) or Regional SKUs on both primary and failover legs [M].
  2. Independent Regional Quota & PTU Reservations: Provisioned Throughput (PTU-M) capacity is reserved per deployment and does not automatically float across regions during an outage [M]. Doubling reserved PTUs idle in Region B costs 2.0× year-round unless paired with an Active-Passive PTU-M + Secondary Standard PAYG / Warm-Anchor topology [Arch].
  3. The Cold-Cache Regional Cutover Surge: Prompt KV caches are strictly local to each deployment/stamp [M]. When an active workload running at 80% prefix cache reuse fails over to a cold secondary region, cached hits drop to 0% for the first 5–15 minutes, spiking normalized input TPM by 1.8×–2.56× right at the moment of cutover [Arch].
  4. Coupled Stateful Agent Dependencies: Multi-turn agents depend on Azure Cosmos DB thread/checkpoint state and Azure AI Search (Foundry IQ) knowledge indexes. Failing over the model endpoint while leaving AI Search or session state stranded in an unreachable primary region still causes 100% turn failure [Arch].
