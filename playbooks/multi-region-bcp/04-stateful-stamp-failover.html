Why It Matters

Azure AI Search does not natively replicate indexes across regions; failing over APIM + Foundry while leaving search or session checkpoints in Region A breaks every RAG-grounded agent turn.

Key Takeaway

Treat ADLS Gen2 (GZRS/RA-GZRS) as the single source of document truth, run independent AI Search stamps per region fed from that storage, and use Cosmos DB multi-region failover for session checkpoints.

Practical Application

Review the 4-component stamp matrix below to verify zero single-region stateful anchors remain in your agent architecture.

Why Model 2 Stateless Agents Simplify Regional Cutover

Because the hub's Model 2 Stateless Agent Pattern (Playbook 01 · Ch 02) persists conversation turns and episodic embeddings in Cosmos DB rather than pinning state inside Foundry server-side thread memory or single-node RAM, an active user conversation seamlessly resumes on Turn N+1 in Secondary Region B with zero lost messages! For DiskANN + RRF hybrid vector indexing, immutable vector policy cutovers, and OneLake-to-AI-Search Shared Private Link parity (D7, D8, D11), see Playbook 05 · Ch 04.
