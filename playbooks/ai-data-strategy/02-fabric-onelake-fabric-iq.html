Why It Matters

Connecting Microsoft Foundry agents directly to raw Bronze lakes or copying tabular ERP data into vector indexes causes hallucinated KPI math, duplicate storage sprawl, and F-SKU capacity throttling.

Key Takeaway

Adopt OneLake zero-copy Shortcuts into a Medallion AI-Ready Gold layer, route structured/analytical questions through Fabric IQ (Ontology + Semantic Models + Fabric Data Agents), index unstructured OneLake Files via Shared Private Link, and separate interactive AI F-SKU capacities from batch ETL.

Practical Application

Use the dual-path grounding diagram and F-SKU isolation checklist below during joint Data Platform + AI Architecture workshops.

1. Medallion Architecture Extended to AI-Ready Gold [Arch] ​

Enterprise data estates already standardize on Microsoft Fabric and OneLake (Bronze → Silver → Gold). Making that estate AI-ready does not require building a parallel shadow data lake. Instead, extend the Gold layer with an explicit AI-Ready Gold contract [Arch]:

  • Bronze (Raw Landing / Zero-Copy Shortcuts): Reference producer domains in ADLS Gen2, Amazon S3, Google Cloud Storage, Dataverse, or cross-workspace Fabric Lakehouses using OneLake Shortcuts rather than duplicating raw bytes [M].
  • Silver (Conformed & Governed): Deduplicate entities, apply Microsoft Purview sensitivity labels and domain ownership, strip PII columns where unnecessary, and validate schema contracts.
  • Gold (Curated Business Truth): Publish governed Delta Parquet tables, Warehouses, and Power BI Semantic Models with certified DAX measures (revenue, margin, exposure, SLA compliance) so every BI dashboard and AI agent shares one mathematical definition [M].
  • AI-Ready Gold (Dual Serving Surface):
    1. Structured & Semantic Surface (Fabric IQ): Bind curated Lakehouse tables, Warehouses, Semantic Models, and Eventhouses to Fabric IQ ontologies and Fabric Data Agents, consumed directly by Microsoft Foundry Agent Service as a grounded tool [M].
    2. Unstructured Document Surface (OneLake Files → Content Understanding → Azure AI Search): Store layout-faithful Markdown and chunk metadata alongside lineage hashes (source_uri, lineage_sha256, sensitivity_label, acl_group_ids) and index via Azure AI Search OneLake Indexer over a Shared Private Link when workspace-level Private Link is enabled [M].

2. Wiring Fabric IQ & Fabric Data Agents Into Microsoft Foundry [M] ​

Fabric IQ unifies business ontologies, Power BI semantic models, Lakehouses, Warehouses, and KQL Eventhouses into a governed semantic context layer over OneLake [M]. Connecting a Microsoft Foundry agent to a published Fabric Data Agent / Fabric IQ tool provides three decisive advantages over ad-hoc text-to-SQL scripts:

  1. Identity Passthrough & Row/Object-Level Security (RLS/OLS): Foundry passes the calling user's Microsoft Entra identity (On-Behalf-Of) to Fabric so existing OneLake Security, Warehouse SQL permissions, and Power BI RLS rules filter every query natively—preventing service-account privilege escalation [M].
  2. Certified Metric Semantics: Queries execute against governed DAX measures and curated Gold schemas rather than guessing table joins across 400 raw staging tables [M] [Arch].
  3. Cache-Safe Tool Schemas (Playbook 01): Registering fabric_iq_query alongside knowledge_base_retrieve in the canonically sorted tools[] array (Pos 2) keeps Pos 1–3 static while appending returned tabular summaries strictly at Position 6 [Arch].

3. Fabric Capacity (F-SKU) Isolation & CU Throttling Math [Arch] ​

Microsoft Fabric bills compute in Capacity Units (CUs) with smoothing (spreading background Spark/ETL bursts over 24 hours and interactive queries over shorter windows) and bursting [M]. When teams attach interactive Fabric IQ agents to the same F-SKU capacity running heavy nightly Spark/Dataflow refreshes, background smoothing debt triggers interactive delay or rejection throttling right during morning executive peak hours [Arch].

Operational Check (Gate D2 & D3)

Before promoting a Fabric IQ tool to production, verify that every Gold table and OneLake File folder carries immutable lineage metadata (source_uri, lineage_sha256, medallion_tier="ai-gold"), and validate interactive CU headroom during a simulated peak agent burst (data_readiness_gate.py rule DRG002).
